# 踩坑（pdd-delist）

| 现象 | 根因 | 正确做法 |
|---|---|---|
| 搜不到商品 | 两个「多个查询」输入框，取错成了规格编码 | 锚定叶子 `商品ID` 再向上取 input |
| 关键词只看到 10 条 | 只读第 1 页 | 翻 `PGT_pagerItem` 所有页；10 条/页 |
| 点「下一页」找不到 | 没有文本按钮 | 点数字页码；不存在时点最大可见页触发展开 |
| 下架后搜不到行 | 已从在售中消失 | 切「已下架」按 ID 回读，不要重复点击 |
| 申请下架提交后弹窗还在 | 理由 textarea 为空 | 必须填 reason；提交后检查弹窗关闭 |
| 确定按钮点不到 | 是 `span` 不是 button | 按叶子文本 `确定` 精确匹配 |
| 关键词枚举数量不对 | 页签 `(34)` 是店铺总在售，不是过滤后 | 以实际翻页收集的 ID 为准 |
| 店铺跑错 | 默认 profile 会变 | 显式 profileId + 回读店铺名 |
| 短时间多次跑 | 风控/页面状态 | 一次只操作一个店；失败即停 |
| 误操作 | 默认真实下架 | 默认 dryRun；live 必须 confirmDestructive |
