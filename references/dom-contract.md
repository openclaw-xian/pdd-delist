# DOM 契约（商品下架）

## 页面

- URL：`https://mms.pinduoduo.com/goods/goods_list`
- 标题：商品列表
- 店铺名：`body.innerText` 中「主账号」前约 60 字
- 页签：全部 / **在售中(N)** / 已下架(N) / 已售罄 / 发布中 / 已驳回 / 草稿箱

## 筛选

- 商品ID：页面有两个 `placeholder="多个查询请空格或逗号隔开依次输入"`，**不能取第一个**；必须锚定叶子文本 `商品ID`，向上 8 层找该行 `input`
- 商品名称：`input[placeholder*="请输入商品名称"]`
- 查询：填值后按 Enter；需要聚焦输入框
- 分页：`li[class*=PGT_pagerItem]`，10 条/页，**没有「下一页」文本**；当前页 class 含 `Active`

## 行读取

- 以最深、可见、叶子文本含 `ID: <goods_id>` 的元素为锚点
- 向上 8 层，取第一个 innerText 命中状态的祖先
- 状态：`销售中` / `已下架` / `审核中` / `发布中` / `已驳回` / `草稿`
- 行内按钮：行容器内叶子文本**精确等于** `下架` / `申请下架`

## 弹窗

### 普通下架

- `[class*=MDL_inner]` 且 innerText 含 `确定下架商品`
- 按钮：叶子 `span` 文本精确 `确定`（不是 button）

### 申请下架

- `[class*=MDL_inner]` 且 innerText 含 `下架原因`
- 点叶子 `其他原因` → 出现必填 `textarea`（placeholder `请输入下架原因`）
- 原生 setter 填 reason → 叶子 `提交`
- 提交后必须检查弹窗是否关闭；空理由点提交弹窗不关

## 复核

- 下架后「在售中」行消失，不是失败
- 切 `已下架` → 按 ID 过滤 → 读行状态
- 关键词模式最后切 `在售中` + 关键词 → 翻完所有页 → 在售中数量必须 0
